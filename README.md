# 🏛️ G3 Architects - Modern Portfolio Landing Page

A professional, clean, and responsive landing page for an architectural firm. This project highlights my core understanding of layout design, typography, and responsive web principles.

🚀 **[Live Demo](https://sabbirhossain778.github.io/g3-architect-website/)**

---

## 🌟 Why this project?
This project marks a significant milestone in my coding journey. I built this during the **first month** of my web development training to master the fundamentals of CSS layouts and mobile responsiveness.

## 🛠️ Tech Stack & Skills
- **HTML5:** Semantic structures for better SEO.
- **CSS3:** Custom properties, Flexbox, and CSS Grid.
- **Responsive Design:** Implemented media queries for mobile and tablet compatibility.
- **Typography:** Integrated Google Fonts (Work Sans) for a professional look.

## ✨ Key Features
- **Hero Section:** Engaging banner with a clear Call-to-Action.
- **Team Showcase:** Responsive image grid display.
- **Service Highlights:** Clean feature cards with modern shadows.
- **Statistics Section:** "Some Facts" area using CSS Grid for milestones.
- **Sponsor Integration:** Minimalist logo section with grayscale effects.
